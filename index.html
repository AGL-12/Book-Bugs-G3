¿Por qué Book & Bugs?

El proyecto Book & Bugs surge como una solución integral para la digitalización de pequeñas y medianas librerías. Esta aplicación de escritorio permite a los administradores controlar el catálogo de libros, usuarios y pedidos en tiempo real, mientras ofrece a los clientes una experiencia de compra fluida e interactiva.

Desarrollada íntegramente en Java con JavaFX para la interfaz gráfica e Hibernate 5.2 como capa de persistencia, la aplicación demuestra un dominio técnico completo del stack académico de PDAM.

Objetivos Técnicos

Metas cumplidas al finalizar el desarrollo del proyecto

01

Persistencia Robusta

Implementar una capa de acceso a datos estable usando Hibernate con configuración JPA y pool de conexiones C3P0.

02

CRUD Administrador

Módulo administrativo completo para gestionar libros, usuarios y pedidos con validaciones y manejo de excepciones propias.

03

Tienda Interactiva

Interfaz de cliente con carrito de la compra, historial de pedidos y sistema de valoración con estrellas.

04

Informes PDF

Generación automática de facturas y listados de inventario mediante la librería JasperReports.

05

Tests Automatizados

Suite de pruebas de interfaz gráfica con TestFX y pruebas unitarias de lógica de negocio con JUnit 4.

06

Documentación Completa

JavaDoc en todas las clases, Manual de Usuario y esta Memoria Web como entregables finales del proyecto.
